# 📍 Projet Humanité Numérique – Backend Flask + SQLite

Ce backend Flask expose les données des anciennes communes du Rhône. Il est utilisé pour visualiser les évolutions administratives (fusions, créations, etc.) dans une carte interactive côté front-end.

---

## 🎯 Objectif

- Scraper les données Wikipédia des anciennes communes du Rhône
- Nettoyer, structurer et stocker les données dans une base SQLite
- Créer une API Flask qui permet de :
  - Consulter toutes les communes et leurs coordonnées GPS
  - Afficher les événements historiques liés à une commune
  - Rechercher les événements par nom de commune et/ou année

---

## 🧰 Prérequis

- Python 3.10 ou supérieur
- SQLite (déjà inclus avec Python)
- DB Browser for SQLite (recommandé)
- Navigateur web ou Postman pour tester les routes API
